1. Pendahuluan & Ringkasan Halaman

Halaman CV (Curriculum Vitae) dibuat pada file app/cv/page.js menggunakan paradigma App Router Next.js. Halaman ini berfungsi mempublikasikan profil profesional kandidat pengembang secara modern, terstruktur, responsif di segala ukuran layar, serta memiliki standar aksesibilitas tinggi (*accessibility*) melalui penerapan tag HTML Semantik.

Penerapan teknologi pada halaman ini mencakup:

  • Next.js File-system Routing: Folder app/cv secara otomatis menjadi endpoint URL /cv yang dapat diakses di peramban web.
  • React Functional Component & JSX: Menggabungkan sintaks markup HTML dengan kekuatan ekspresi dinamis JavaScript dalam satu file terpadu.
  • Tailwind CSS (Utility-First): Membangun tata letak adaptif menggunakan flexbox, css grid, serta varian dark: untuk mendukung tema gelap (*Dark Mode*).
  • Aksesibilitas & SEO: Memastikan hierarki heading tertata dari <h1> hingga <h3> tanpa ada tingkatan yang terlewat, serta seluruh form terhubung dengan labelnya.

4. Analisis Kode Sumber (app/cv/page.js) - Bagian 1

A. Deklarasi Komponen dan Variabel Dinamis

export default function HalamanCV() { const nama = "Bhayu Satria Sugara"; const kelasInput = "w-full rounded-lg border border-slate-300 px-3 py-2"; return ( ... ); }
Penjelasan:
  • export default: Komponen utama yang dicari oleh Next.js untuk merender rute URL /cv.
  • const nama: Mengadopsi prinsip DRY (Don't Repeat Yourself). Nama hanya didefinisikan satu kali, lalu dipanggil di berbagai elemen dengan kurung kurawal {nama}.
  • const kelasInput: Menyeragamkan styling kolom form input dan textarea agar kode bersih dan mudah diperbarui.

B. Header & Navigasi Semantik

<header className="bg-teal-800 text-white"> <div className="mx-auto flex max-w-4xl flex-col gap-4 px-4 py-8 md:flex-row md:items-end md:justify-between"> <div> <h1 className="text-3xl font-bold md:text-4xl">{nama}</h1> <p className="text-teal-100">Junior Programmer</p> </div> <nav className="flex flex-wrap gap-4 text-sm"> <a href="#tentang" className="hover:underline">Tentang</a> <a href="#pendidikan" className="hover:underline">Pendidikan</a> <a href="#keahlian" className="hover:underline">Keahlian</a> <a href="#pengalaman" className="hover:underline">Pengalaman</a> <a href="#kontak" className="hover:underline">Kontak</a> </nav> </div> </header>
Poin Desain:
  • max-w-4xl mx-auto: Menjaga lebar konten tetap terpusat di tengah layar desktop.
  • flex-col md:flex-row: Di layar HP menu bertumpuk ke bawah, lalu otomatis berjajar horizontal di layar medium ($\ge 768\text{px}$).
  • Hanya ada satu <h1> di seluruh halaman demi kepatuhan standar SEO dan aksesibilitas.

F. Formulir Kontak Berbasis CSS Grid

<form className="grid gap-4 md:grid-cols-2"> <div className="space-y-1"> <label htmlFor="nama" className="block text-sm font-semibold">Nama</label> <input type="text" id="nama" name="nama" required className={kelasInput} /> </div> ... <div className="space-y-1 md:col-span-2"> <label htmlFor="pesan" ...>Pesan</label> <textarea id="pesan" name="pesan" rows={4} required className={kelasInput}></textarea> </div> </form>
Poin Penting:
  • htmlFor: Pengganti atribut for standar HTML di JSX agar tidak bentrok dengan keyword perulangan JavaScript.
  • grid md:grid-cols-2: Kolom Nama & Email menjadi 2 kolom berdampingan di layar desktop.
  • md:col-span-2: Mengatur elemen Pesan dan Tombol Kirim agar merentang penuh selebar 2 kolom.
